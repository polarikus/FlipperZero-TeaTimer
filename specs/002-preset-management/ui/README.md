# Референсные макеты UI — управление пресетами (фича 002)

Каталог — визуальный референс к [spec.md](../spec.md): выбор пресета через штатный
экран выбора файла и создание/правка пресета прямо на устройстве. Макеты нужны, чтобы
согласовать экраны **до** разработки.

## Что внутри

```
ui/
├── README.md            — этот файл: карта экранов, правила, что можно менять
├── wireframes.md        — те же экраны в ASCII (быстрый просмотр в ревью)
└── mockups/
    ├── generate.py              — генератор макетов (правим его, а не SVG руками)
    ├── 01-main-menu.svg         — главное меню: Presets / New preset
    ├── 02-file-browser.svg      — выбор пресета (стандартный браузер файлов)
    ├── 03-preset-card.svg       — карточка пресета + Start + Edit
    ├── 04-name-keyboard.svg     — ввод названия (стандартная клавиатура)
    ├── 05-number-keypad.svg     — ввод числа (цифровая раскладка)
    ├── 06-new-summary.svg       — сводка перед сохранением
    ├── 07-error-value.svg       — значение вне диапазона
    ├── 08-saved.svg             — пресет сохранён
    └── preview/*.png            — PNG-превью (512×256, ×4)
```

Пересобрать после правки `generate.py`:

```bash
python3 specs/002-preset-management/ui/mockups/generate.py
```

Масштаб: экраны нарисованы в реальном разрешении устройства — **128×64 px**, монохром,
увеличены в 4 раза только для просмотра. Шрифт в макетах моноширинный: на устройстве
будет шрифт прошивки, поэтому ширина строк примерная.

## Экраны подробно

| # | Экран | Когда показывается | Обязательные элементы |
|---|-------|--------------------|------------------------|
| 01 | Main menu | при открытии приложения | заголовок `Tea Timer`, пункты `Presets`, `New preset`, подсказка `OK: open` |
| 02 | File browser | выбран пункт `Presets` | путь/имя каталога, список `.tea`-файлов и папок с иконками, выделение, подсказка `OK: open` |
| 03 | Preset card | выбран корректный `.tea` | название, `Leaf x g/100ml`, `First MM:SS`, `Step MM:SS`, `Max N pours`, кнопка `START`, подсказка `>: edit` |
| 04 | Name (keyboard) | пункт `New preset` / `Edit` | поле ввода с курсором, клавиатура, подсказка `OK: enter` |
| 05 | Number (keypad) | после названия, по одному полю | заголовок поля, значение с курсором, цифровая раскладка, подсказка `OK: enter` |
| 06 | Summary | все поля заполнены | название и все четыре значения, подсказка `OK: save` |
| 07 | Out of range | значение не прошло проверку | что не так и допустимый диапазон, `OK: retry` |
| 08 | Saved | файл записан | имя файла, каталог, `OK: open preset` |

## Правила вёрстки и поведения (для реализации)

1. **Стандартные компоненты вместо самодельных.** Выбор пресета — штатный экран выбора
   файла (как «File Select» в приложении-примере), ввод текста и чисел — штатная
   экранная клавиатура. Внешний вид не перерисовываем, добавляем только заголовки.
2. **Своё — только карточка пресета и сводка.** Это единственные экраны, которые
   приложение рисует само, поэтому на них всё внимание к значениям.
3. **Экран 128×64, монохром.** Инверсия — только для акцента: выбранный пункт меню,
   выделенная строка браузера, кнопка `START`, выбранная клавиша, заголовок диалога.
4. **Все подписи короткие и английские**: `Presets`, `New preset`, `Leaf`, `First`,
   `Step`, `Max`, `START`, `OK: open`, `OK: enter`, `OK: save`, `Out of range`, `Saved`.
5. **Каждое значение — отдельный шаг с предзаполненным типом** (5.0 / 20 / 5 / 6), чтобы
   не набирать с нуля: пользователь правит «типичный» пресет под свой чай.
6. **Ошибка — диалог поверх формы**, после `OK: retry` возвращаемся в то же поле с уже
   введённым значением, ничего не сбрасываем.
7. **Название на экране обрезается многоточием**, но в файл пишется полностью.

## Управление

| Кнопка | Menu | File browser | Preset card | Форма ввода |
|--------|------|--------------|-------------|-------------|
| Up/Down | переключение пункта | перемещение по списку | — | перемещение по клавишам |
| Left/Right | — | — | `Edit` (вправо от Start) | перемещение по клавишам |
| OK | открыть пункт | открыть файл/папку | запустить пролив | подтвердить значение (`enter`) |
| Back | выход | вверх по каталогу / в меню | назад в браузер | отмена: назад на предыдущий шаг |

## Что удобно менять до разработки

- **Точка входа**: оставить меню из двух пунктов или открывать выбор файла сразу при
  запуске, а `New preset` поместить отдельным пунктом в конец списка файлов.
- **Карточка пресета**: показывать ли все пять параметров (`First`/`Step`/`Max`) или
  только `Leaf` и время первого пролива, как на экране заваривания из 001.
- **Количество шагов формы**: отдельный шаг на каждое число (4 шага) или один экран со
  всеми полями и переходом по Tab.
- **Ввод числа**: цифровая раскладка штатной клавиатуры или инкремент/декремент
  `Left`/`Right` по разрядам (быстрее, но непривычно).
- **Набор символов в названии**: разрешить ли кириллицу (на экране не отобразится) ради
  удобства копирования на компьютер.
- **Конфликт имён файлов**: суффикс `_2` автоматически или явный вопрос «Overwrite?».
- **Правка**: нужно ли `Edit` на карточке (P3) и не заменить ли его полноценным
  файловым менеджером с удалением пресета.
